# 🎬 Movie Booking System

## 📌 About the Project

The **Movie Booking System** is a web-based application designed to simplify the process of browsing movies and booking tickets online. It provides users with an easy-to-use interface to view available movies, select show timings, choose seats, and confirm bookings.

The system is built to simulate a real-world cinema booking experience, similar to platforms like BookMyShow. It helps users avoid long queues and allows administrators to manage movies, show timings, and bookings efficiently.

This project demonstrates core concepts of full-stack development, including user authentication, database management, and CRUD operations.

---

## 🚀 Features

* 👤 User Registration and Login
* 🎬 Browse available movies
* 🕒 View show timings
* 💺 Interactive seat selection
* 🎟️ Book movie tickets online
* 📜 View booking history
* 🛠️ Admin panel for managing movies and shows (if implemented)
* 🗄️ Database integration for persistent data storage

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/meerabztx/movie-booking-system.git
cd movie-booking-system
```

### 2. Install dependencies

For Node.js:

```bash
npm install
```


### 3. Configure database

* Create a database (e.g., `movie_booking`)
* Import provided SQL file 
* Update DB credentials in config file

### 4. Run the project

```bash
npm start
